# 🍕 Food Delivery Analytics Dashboard

An interactive Power BI dashboard analyzing food delivery performance, order patterns, and revenue key performance indicators (KPIs).

---

## 📌 Project Overview
This repository contains a complete Power BI Project (`.pbip`) configured for tracking key metrics in a food delivery ecosystem.

* **Format:** Power BI Project (`.pbip`)
* **Tool Used:** Microsoft Power BI Desktop

---

## 📁 Repository Structure
* `Food_Delivery_Dashboard.pbip` - Main Power BI project file
* `Food_Delivery_Dashboard.Report.zip` - Contains report layout, visuals, and theme configurations
* `Food_Delivery_Dashboard.SemanticModel.zip` - Contains the data model, DAX measures, and dataset logic
* `.gitignore` - Standard gitignore for Power BI temporary files

---

## 🛠️ Key Analysis & Features
* **Order & Revenue Analysis:** Overall order volume, total sales, and revenue breakdown.
* **Delivery Performance:** Delivery time efficiency and status tracking.
* **Customer Insights:** Order frequency and top-performing food categories.
