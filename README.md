# 🍕 Food Delivery Analytics Dashboard

An interactive Power BI dashboard analyzing food delivery performance, order patterns, and key revenue metrics.

---

## 📌 Project Overview
This repository contains a ready-to-use Power BI Report file (`.pbix`) designed to evaluate business performance across order volumes, delivery metrics, and customer purchasing trends.

* **Format:** Power BI Report (`.pbix`)
* **Tool Used:** Microsoft Power BI Desktop

---

## 📁 Repository Structure
* `Food_Delivery_Dashboard.pbix` - Complete Power BI report file containing data model, DAX measures, and interactive report pages.
* `README.md` - Documentation and project summary.

---

## 🛠️ Key Analysis & Features
* **Order & Revenue Tracking:** Real-time visibility into overall sales, average order value (AOV), and total order volume.
* **Delivery Performance:** Analysis of average delivery times, rider efficiency, and fulfillment rates.
* **Customer Insights:** Breakdown of popular food categories, repeat order behavior, and peak time patterns.

---

## 🚀 How to Run
1. Click the **`Code`** button above and select **Download ZIP** (or clone the repository).
2. Ensure you have **Microsoft Power BI Desktop** installed on your system.
3. Open `Food_Delivery_Dashboard.pbix` to interactively explore the dashboard and underlying data model.
